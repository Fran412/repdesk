How it works

Two portals. One problem solved.

Course Rep
Create a payment drive
Log in with your rep account. Set the drive name, amount, and deadline. Upload your class list — Excel, PDF, Word, or plain text, any format works. The platform registers every name and matric number.
Student
Find your name and submit
No account. No login. Students open the portal, find their name in the class list, and either pay directly via Paystack or upload a bank receipt screenshot. The system reads the receipt automatically.
System
Automatic fraud detection
Every receipt is scanned on upload. Duplicate reference numbers, wrong amounts, and mismatched dates are flagged instantly without the rep having to check manually. Suspicious submissions go into a review queue.
Course Rep
Monitor everything in real time
The rep dashboard updates the moment a student submits. See exactly who has paid, who hasn't, and which receipts need a second look. Export the full register when collection is complete.
Features

Everything the rep needs. Nothing they don't.

Secure rep login
Each course rep has their own private account. Their class data, drives, and submissions are completely separate from every other rep on the platform.
Any file format
Upload your class list as Excel, PDF, Word, CSV, or plain text. Paste it directly if you prefer. The platform parses it and registers every student automatically.
AI receipt scanning
Students upload a screenshot of their bank receipt. The system extracts the reference number, amount, bank, and date automatically. No manual entry on either side.
Paystack integration
Students who haven't paid yet can pay directly through a Paystack link. Payment is confirmed automatically — no receipt needed, no verification delay.
Duplicate detection
If two students submit the same reference number, both are flagged immediately. Amount mismatches are caught the same way. The rep decides how to handle each case.
Works at any university
No school is hardcoded. Any rep at any Nigerian university can create an account, set up their department, and start a drive in under five minutes.
Course Rep
